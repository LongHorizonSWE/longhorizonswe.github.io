# Long-Horizon Software Engineering Agents: From Tasks to Projects

Project website: **https://longhorizonswe.github.io/**

Main project repository: **[Awesome-LongHorizonSWE](https://github.com/LongHorizonSWE/Awesome-LongHorizonSWE)**

This repository hosts the project website for the survey. The website currently contains a minimal coming-soon page; its design and content will be added later. The `longhorizonswe.github.io` repository name provides the organization website's root URL; the main project retains the `Awesome-LongHorizonSWE` name.

The manuscript, Overleaf sources, figures, and PDF are maintained separately.

## Website updates

Edit `index.html` and push to `main`. The GitHub Pages workflow automatically publishes the website at the organization URL above. Only `index.html` and `.nojekyll` are included in the deployment.
